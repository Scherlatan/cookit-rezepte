# Cookit-Rezepte

Eigene und umgeschriebene Rezepte für den Bosch Cookit – mit allen Geräteeinstellungen
(Werkzeug, Stufe, Temperatur, Dauer) pro Schritt.

Jedes Rezept hat eine eigene Seite unter `rezepte/<name>/`. Die Seite dient zum Nachlesen am Handy,
zum Abtippen in die Home Connect App („Mein Rezept“) und als Link für den KI-Rezeptumwandler der App.
